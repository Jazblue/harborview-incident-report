## What This Is

A fictional incident response report for **Harborview Accounting & Tax Services**, a 22-employee small business that suffered a ransomware attack. The report walks through the full investigation: initial evidence, timeline reconstruction, hypothesis analysis, root cause identification, remediation steps, and lessons learned.

The report is presented as a single-page static website (`index.html`) with no dependencies.

---

## Key Findings

- **Attack type:** Double extortion ransomware (encryption + data exfiltration)
- **Entry vector:** Service account credential theft from a plaintext file on a stolen laptop
- **Attacker behavior:** Direct access to file server, no lateral movement, custom PowerShell payload
- **Detection gaps:** SIEM threshold bypass, no EDR on file server, Windows Defender missed custom payload
- **Outcome:** 4,892 files encrypted, 500MB of client data exfiltrated
